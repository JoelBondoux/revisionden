### Changed

- G13: changelog fragments. Each pull request now adds `changes/unreleased/<branch>.md` instead of editing the shared `## [Unreleased]` block of `CHANGELOG.md`, which made nearly every open pull request conflict after each merge. `pnpm changelog:assemble` (`scripts/changelog.mjs`) folds them in; the release workflow runs it on `main` before dating the section, and deploys fold them into the build's copy so the About page still shows unreleased What's new lines. A new **Changelog fragment** check (`.github/workflows/changelog.yml`) fails a pull request into `dev` without one, unless it is labelled `no-changelog` or only touches tests or CI. `.gitattributes` merges `CHANGELOG.md` and `docs/WORKSTREAMS.md` with `merge=union` locally. Tests: `scripts/changelog.test.mjs`.
