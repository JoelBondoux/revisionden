# J15s: every effect style is a full look

The owner, trying the styles on dev (2026-11-26): "When I change theme only the Today box on the Map
page changes."

Each style now restyles the whole app: page, cards, edges, corners, shadows, the main colour,
chips, the menu bar, the map, headings and its own background pattern. Text stays readable (AA) in
every style, light and dark, and with colour-blind friendly colours.

Screenshots of the real build (made-up demo data), left to right: Doodle Diary (the default),
Sticker Book, Pop Burst, Starlight, Comic Pop, Garden Grow, Pixel Arcade.
